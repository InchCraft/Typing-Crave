# Typing Crave

**A simple, fun and customizable typing speed test.**

Typing Crave is a browser-based typing test created to help people test and improve their typing speed and accuracy using fun sentences and a clean customizable interface.

## Features

- **WPM Tracking** – Track how fast you type in words per minute.

- **Accuracy Tracking** – Check how correct your typing is.

- **Live Feedback** – See which keys you type correctly and which ones you get wrong as you type.

- **Sound Effects** – Hear feedback while you type and when you finish a test.

- **Customizable Themes** – Pick from Classic, Dark and Light modes.

- **Built-in Prompts** – A list of sentences to make each test exciting.

- **No Downloads Required** – Works, in your browser.

## Getting Started

1. Go to the Typing Crave website.

2. Begin typing the sentence that appears on the screen.

3. Finish the test.

4. Look at your WPM and accuracy.
